# Docker and Kubernetes course exercises

Exercise projects and cheat sheets from a Docker and Kubernetes course I worked through in early 2024. Kept as a learning record, not as a reference implementation.

Folders map to course sections: images and containers, docker-compose, multi-container apps, utility containers, and a Laravel setup with Nginx and PHP-FPM behind compose.

What I actually use from this now lives in [loyaone-infra-terraform](https://github.com/keniiy/loyaone-infra-terraform) and [CLOUD-TRANSITION](https://github.com/keniiy/CLOUD-TRANSITION).
